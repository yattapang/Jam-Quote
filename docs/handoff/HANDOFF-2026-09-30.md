## 6. Working rules that cost the most to learn this session

- **Never `git checkout --` or `git restore`.** Plant from a backup copy, restore from it, `diff -q`.
- **Never edit a committed migration (Rule 6)** — correct it in a new one, naming the file it corrects.
- **Every claimed property gets its own plant** (M35): a test red for the reported defect is not proof of
  every property the fix claims.
- **A brief's expectations run last, on the exact HEAD it names** (M36, M37).
- **Declare the tier in `docs/BRIEF-STATUS.md` before every agent launch**, commit it, and never commit or
  run the gate while an agent is live — its planted defects are in the tree.
- **Financial writes must run READ COMMITTED**; two deadlock shapes remain and are retryable
  (`new-app/CLAUDE.md`).
- **A reviewer's findings live in the scratchpad until copied into `docs/PRD-REVIEW-4.md`** — copy them
  in and commit before anything else.

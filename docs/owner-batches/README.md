# Owner batches

One file per batch of owner actions, `batch-1.md` onward, written and committed when that batch's stage is reached
(`docs/OWNER-ACTIONS.md`, "How it works"). Each file is the complete request for every action in its batch: the
steps, the exact values to enter, what to send back, and why each action is needed and by which build step.
